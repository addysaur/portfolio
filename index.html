KisanLabel

Pesticide Label Reader for Indian farmers. Photograph a label → Gemma extracts it, Python does the dose maths (verified: 40.0 ml for 2.5 ml/L in 16 L), soil cautions included. Final version runs fully local via Ollama gemma3:4b — no API key, offline once pulled. Team of 4, merged to main via PR #4, then selected for XERJ's public Corpus Hub under MIT with attribution.
