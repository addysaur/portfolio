About the wanderer

The lights got dimmer. The wallpaper is gone. This is where the real work happens — Python, machine learning fundamentals, and learning to build things that actually run locally, offline, for real people.

I am Advait Bodkhe, known as Addy, a first-year B.Tech student in Artificial Intelligence and Machine Learning at Newton School of Technology, Pune, where I joined in August 2026. I am in the Turing batch, Lab Lambda, and I am still early in the degree, so most of my skill so far comes from building small, real things and fixing them when they break, rather than from claiming experience I do not have yet.

Between lectures I build AI tools, digital products, and video edits. My main project so far is KisanLabel, a pesticide-label reader for Indian farmers that runs fully offline on a local Gemma model, which my team built for Hacktoberfest and which was later selected for XERJ's public Corpus Hub. I also built RescueRoute AI, a surplus-food rescue matcher for the CoNSTruct 2.0 hackathon, and I sell a small digital product, The College Prompt Pack, on Gumroad. Outside code I brand and edit for FrameDrop, our college society for video editors and cinematographers, and I film as a core-committee videographer for the MMA club.

What I am working on now is consistency: stronger Python fundamentals, especially loops, lists and recursion, better maths for machine learning, and getting comfortable on the command line. I am also learning to work in the open — documenting what I build, writing clear commit messages, and contributing to open source, including ten maintenance pull requests on the Exercism TypeScript track. I am open to hackathons, collaborations, and freelance editing work, and I would rather show a small thing that actually works than describe a big thing that does not exist yet.

KisanLabel

Pesticide Label Reader for Indian farmers. Photograph a label → Gemma extracts it, Python does the dose maths (verified: 40.0 ml for 2.5 ml/L in 16 L), soil cautions included. Final version runs fully local via Ollama gemma3:4b — no API key, offline once pulled. Team of 4, merged to main via PR #4, then selected for XERJ's public Corpus Hub under MIT with attribution.

Technologies: Python · FastAPI · Streamlit · Ollama gemma3:4b · Git / GitHub

Source code: github.com/PrinceVerma44/Pesticide-Label-Reader-for-Indian-Farmers-Spooky_Wookys ↗

Perplexity Explorer — Dreamcore

A perplexity explorer that runs a real DistilGPT-2 model in the browser with Transformers.js — no backend, no API key. Type a sentence, get its perplexity, the top-8 next-token predictions, and a step-by-step by-hand calculation. The score drives a judging-chamber scene with Pepe and V.

Technologies: JavaScript · HTML / CSS · Transformers.js · DistilGPT-2 (Xenova/distilgpt2)

Source code: github.com/addysaur/perplexity-explorer-dreamcore ↗
Live demo: perplexity-explorer-dreamcore.vercel.app ↗
